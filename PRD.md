## 🧾 User Story:

### 1. Sort by Price

- [x] Along with the multiple filters on the product listing page on the sidebar, add a feature to sort products by price.
- [x] Price: A select button to sort from low to high & high to low.

### 2. Product Detail Page

- [x] If you click on any product you should be redirected to a single product page with all its details & the "Add to Cart" & "Add to Wishlist" buttons.

### 3. Wishlist Management

- [x] From the navbar, you can navigate to your wishlist where all the products that you liked and wish to buy in future are mentioned.
- [x] On the product card:
  - [x] You can remove the item from the wishlist.
  - [x] Add the item to the cart.
  - [x] If the cart already contains that item, it should only increase the quantity.

### 4. Cart Management

- [x] From the navbar, you can navigate to the cart where all the products that you want to buy are mentioned.
- [x] On the product card:
  - [x] You can see the quantity of a particular product.
  - [x] You can Increase or Decrease the quantity of a particular product.
  - [x] Remove the product from the cart.
  - [x] Add the product to the Wishlist.
- [x] You can see the price details card of the cart containing a button to checkout which will show the total price of the products with its quantity.

### 5. Address Management

- [x] You can add multiple addresses, update or delete them.
- [x] You can choose a single address to deliver the order.

### 6. Checkout

- [x] Once you choose the address, you can click on the checkout button which would show the order summary.
- [x] Show a message, "Order Placed Successfully" on the order summary page, after the order is placed.

### 7. User Profile

- [x] You can see the user profile with details containing the name, email Id, phone number, address, etc.

### 8. Loading & Alerts

- [x] You can see loading messages when the data i.e. the products are loading.
- [x] You can see the acknowledgement alerts whenever you:
  - [x] Add item to the cart
  - [x] Remove Item from the cart
  - [x] Increase or Decrease item in the cart
  - [x] Move an item from the cart to the wishlist
  - [x] Add item to the wishlist
  - [x] Remove Item from the wishlist
  - [x] Move an item from wishlist to cart

### 9. Search

- [x] You can search for an item from the product list via the input text box on the header navbar.
